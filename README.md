# 🏡 FamLink (팜링크) - 가족 전용 소통 & 게이미피케이션 플랫폼

> **"대화가 줄어든 가족에게 따뜻한 소통의 핑계를 선물합니다."**  
> **FamLink**는 가족 전용 단톡방/1:1 메신저, 데일리 소통 미션(스몰톡), 공유 캘린더, 장보기 체크리스트, 포인트 쿠폰 상점 & 입출금 내역장, 그리고 **온 가족이 함께 모은 포인트로 실물 책을 제작·인쇄하는 AI 가족 이야기책 출판 스튜디오**가 결합된 **가족 전용 올인원 게이미피케이션 라이프스타일 플랫폼**입니다.

---

## 🌟 주요 기능 (Key Features)

### 0. 🏠 FamLink 통합 홈 대시보드 (Figma Design Home Dashboard)
- **Figma 디자인 기반 올인원 대시보드 (`HomeScreen.js`)**:
  - **패밀리 헤더 & 날짜/인사말**: 오늘의 날짜, 맞춤 가족 인사말(`Good morning, 우리 가족 👋`) 및 포인트 뱃지(`⭐ 1240 pts`) 상시 표시
  - **가족 구성원 퀵 레일**: 역할/프로필별 고유 컬러 링 아바타 및 `+` 멤버 초대 버튼
  - **오늘 함께 진행도 (`Today's Together Activities`)**: 코랄-오렌지 그라디언트 캡슐 게이지 및 완료 잔여량 실시간 트래킹
  - **Your Family Pet 전용 위젯**: 페리윙클 그라디언트 카드에 현재 반려몽의 3대 생체 게이지(체력, 행복도, 포만감) 실시간 표시 및 1-tap 룸 진입
  - **Family Chat 프리뷰 카드**: 가족 단톡방의 최신 4개 대화 스니펫 및 `Open chat →` 다이렉트 이동
  - **Your Family Book 출판 티저**: 이번 달 수집된 추억 통계 및 글래스모피즘 `Preview book →` 바로보기 연동

### 1. 💬 가족 실시간 메신저 (Advanced Chat System)
- **1:1 격리 대화방 & 단체 수다방**: 독립된 1:1 대화방(대칭 룸 ID)과 전체 가족 수다방 완벽 분리
- **카카오톡 스타일 읽음 카운터 (`1`, `2`)**: 상대방이 메시지를 읽는 즉시 실시간으로 숫자가 차감되는 투명한 읽음 확인
- **0ms 초고속 낙관적 UI (Optimistic UI)**: 메시지 전송 버튼을 누르는 즉시 화면에 반응하고 백그라운드에서 동기화
- **클라이언트 고화질 이미지 95% 압축 (`compressImageForChat`)**: 4K 스마트폰 사진을 80KB 수준으로 고속 압축 전송
- **PC 웹 & 모바일 UX 최적화**: 
  - PC 환경에서 `Enter` 즉시 전송 & `Shift + Enter` 줄바꿈 지원
  - 모바일 가상 키보드 가림 완벽 방지 (`KeyboardAvoidingView` + 홈 바 세이프 패딩)
- **스마트 상단 하이라이트 배너**: 오늘의 스몰톡 미션 상태 및 최근 답변 실시간 프리뷰
- **시스템 스페셜 알림 카드**: 쿠폰 사용 및 실물 책 발주 시 골드/코랄 축하 카드로 단톡방 자동 공지

### 2. 🤝 오늘 함께 허브 (Together Hub - SmallTalk & Chores)
*가족의 하루 소통(스몰톡), 생활 루틴(집안일), 온가족 미니게임을 편안하게 함께 즐기는 패밀리 라이프스타일 허브입니다.*

#### ① 💬 서브 탭 1: 데일리 스몰톡 (소통 미션)
- **일일 질문 자동 순환**: 매일 새로운 대화 주제를 던져주어 가족 간 자연스러운 대화 유도
- **고유 프로필 기반 답변 격리**: 동일한 역할(예: 아들 2명) 사용자 간에도 답변이 섞이지 않는 1:1 고유 UUID 매핑
- **개인 기여 + 가족 전원 보너스 이원화 보상**: 답변 작성 시 1인당 **+5P** 즉시 적립 + 가족 전원 답변 완료 시 **+30P** 올클리어 보너스 지급 (대규모 가족도 소외 없이 안정적 적립)
- **10인 가족 전용 UI/UX 최적화**: 10인 대가족 환경에서도 스크롤 없이 바로 쓸 수 있는 **답변창 상단 우선 배치** 및 **가족 참여 현황 퀵 레일(가로 아바타 칩)** 제공
- **순수 대화 집중 레이아웃**: 상점/펀딩 카드를 분리하여 가족들의 따뜻한 답변과 말풍선에 온전히 몰입

#### ② 🛒 서브 탭 2: 가족 장보기 & 심부름 (생활 미션)
- **담당자 지정 체크리스트**: 필요한 장보기 물품 및 집안일 등록 및 담당 가족 지정 (최대 10인 가족 아바타+이름 동시 지원)
- **매일/정기 반복 할 일 설정 & 자정 자동 갱신**: 분리수거, 화분 물주기, 반려견 산책 등 매일 반복되는 집안일을 위한 반복 설정(`반복 없음` / `매일 반복` / `매주 반복`) 지원, 자정 이후 새로운 오늘 할 일로 자동 리셋 및 완료 비우기 시 루틴 데이터 영구 보존
- **순수 SVG 반복 아이콘(`IconRepeat`) 연동**: 이모티콘 없이 직관적인 SVG 벡터 뱃지 탑재 및 원터치 반복 전환 토글 지원
- **어뷰징 방지 보상 시스템**: 최초 1회 체크 시 1건당 **+10P** 지급, 하루 최대 30P(3건)로 일일 캡 제한
- **임베디드 컴팩트 뷰**: 별도 탭 이동 없이 미션 탭 안에서 원스톱으로 체크 및 추가 가능

#### ③ 🎁 서브 탭 3: 포인트 & 혜택 (보상 & 출판 센터)
- **가족 공동 버킷리스트 펀딩 (Co-op Goal)**:
  - 온 가족이 함께 모은 총 포인트로 공동의 목표를 달성하는 펀딩 프로그레스 바
  - **100% 달성 완료 & 포인트 파티 사용 플로우**: 100% 달성 시 `[버킷리스트 달성! 포인트 사용하고 파티 열기]` 버튼 활성화 ➔ 포인트 정산 차감(`onDeductPoints`) ➔ 가족 단톡방 자동 축하 공지 발송(`onSendOrderNotice`) ➔ 명예의 전당 영구 아카이빙 ➔ 다음 목표 설정 연결
  - **🏆 우리가 이룬 버킷리스트 (명예의 전당)**: 모은 포인트로 달성한 역대 버킷리스트 목록 및 달성 일자 영구 보존
  - **Lucide SVG 벡터 아이콘 전면 적용**: 이모티콘 대신 `BookOpen`, `Utensils`, `Compass`, `Tv`, `Coffee`, `PartyPopper`, `Trophy` 등 정밀한 SVG 아이콘 시스템 탑재
  - 추천 프리셋(6개월 실물 이야기책 출판 2,500P, 외식 3,000P, 글램핑 여행 5,000P 등) 및 맞춤형 목표 생성
- **📖 AI 가족 이야기책 출판 스튜디오 (POD Engine)**:
  - **6개월(반기) 마스터피스 발주 시스템 (2,500 P)**: 6개월 동안 모은 가족 포인트로 실물 하드커버 양장본 제작 신청 (연 2회 출판 사이클)
  - **A5 표준 판형 (148 × 210mm) / 300 DPI** 출판 인쇄 규격 북 뷰어
  - **총 8페이지 체계적 도서 구성**: 겉표지(4가지 테마), 프롤로그, 스몰톡 문답 매거진(2P), 포토 갤러리 에세이(2P), Gemini 2.5 Flash 기반 AI 가족 수필 편찬, 판권지(ISBN 예비 번호 및 용지 스펙)
  - **실물 양장 하드커버 도서 발주 주문 Flow (A5 규격 POD 엔진)**
- **포인트 쿠폰 상점 & 내 쿠폰함**:
  - 가족 커스텀 쿠폰 등록, 등록자(제공자) 수정/삭제 권한 통제
  - 쿠폰 사용 승인 확인 팝업 및 가족 단톡방 자동 축하 공지 연동
- **포인트 입출금 내역장 (Point Ledger)**: 총 획득/사용/잔여 요약 및 타임라인 장부 영구 보존

### 4. 🐾 반려몽 캐주얼 육성 게임 엔진 & 감성 룸 (Petmong Game & Care)
- **체류형 인터랙티브 4대 미니게임 시스템 (`components/minigames/`)**:
  - **제1탄 [와구와구 간식 캐치] (`SnackCatchGame.js`)**: 밥주기(`🍗`) 메뉴에서 플레이 가능한 30초 아케이드 미니게임. 하늘에서 떨어지는 사과(🍎), 고기(🍖), 케이크(🍰), 별사탕(⭐)을 반려몽을 직접 좌우로 스와이프 컨트롤하여 받아먹는 손맛 중심 게임플레이. 폭탄(💣)과 매운 고추(🌶️) 회피, 8연속 콤보 피버 타임(🔥 2배 점수), 포만감 100% 완충 및 대량 EXP·가족 포인트(P) 보상.
  - **제2탄 [핑퐁 리프팅 랠리] (`KeepyUppyGame.js`)**: 놀아주기(`⚽`) 메뉴에서 플레이 가능한 인터랙티브 핑퐁 리프팅 게임. 바닥에 공이 떨어지지 않도록 유저가 손가락 패들로 튕겨 올려 반려몽의 헤딩/슛과 탁구/배구 랠리를 이어가는 쾌감 액션. 랠리 횟수 콤보, 점진적 속도 증가 긴장감, 황금 볼(✨ 2배 점수) 모드, 행복도 100% 완충 및 S/A/B/C 등급별 대량 EXP·가족 포인트 보상.
  - **제3탄 [뽀득뽀득 버블 팝] (`BubblePopGame.js`)**: 목욕하기(`🧼`) 메뉴에서 플레이 가능한 비누방울 터트리기 쾌감 액션 게임. 따뜻한 스파 욕조 속 반려몽 주변으로 솟아오르는 비누방울들을 손가락으로 연속 탭/슬라이스하여 팡팡 터트려 청결도 100% 게이지 달성. 황금 거품, 시간 연장(⏱️ +3초, 최대 2회 제한), 슈퍼 비누, 8콤보 스파클 피버 모드 및 S/A/B/C 등급별 대량 EXP·가족 포인트 보상.
  - **제4탄 [꿈나라 별자리 잇기] (`DreamConstellationGame.js`)**: 재우기(`🌙`) 메뉴에서 플레이 가능한 힐링 감성 별자리 선 잇기 퍼즐. 푹 잠든 반려몽 머리 위 깊은 밤하늘에 빛나는 별들을 1번부터 차례대로 드래그/탭 연결하여 꼬마곰자리, 하트자리, 왕관자리, 반려몽 수호자리를 완성. 깜짝 별똥별(🌠) 소원 보너스, 꿀잠 에너지 100% 완충 및 S/A/B/C 등급별 대량 EXP·가족 포인트 보상.
- **다마고치식 실시간 캐주얼 게임 엔진 (`PetmongGameEngine.js`)**:
  - **1가족 1공동 수호 반려몽 (Family Co-op Petmong)**: 개인별 플레이에서 탈피하여 온 가족이 함께 돌보는 우리 집 대표 수호 반려몽 시스템 구축. 가족 전원의 스몰톡, 집안일, 미니게임 플레이가 하나의 가족 반려몽 경험치로 누적 합산.

  - **스팸 연타 쿨다운 UI & 게이지 100% 거절 리액션 & 어뷰징 방지**:
    - **진행 중 쿨다운(비활성화) 피드백**: 동작 실행 중 버튼이 `식사중/놀이중/목욕중` 라벨과 함께 반투명(0.45) 쿨다운 상태로 전환되며, 연타 시 `"지금 맛있게 냠냠 먹는 중이에요!"`, `"지금 샤워 중이에요!"` 실시간 토스트로 안내하여 먹통 오인 방지.
    - **다마고치 감성 100% 거절 리액션**: 포만감 100% 시 고개 도리도리 모션과 함께 `"배가 빵빵해서 더는 못 먹어요 몽! 🤰✨"`, 청결도 100% 시 반짝이 표출과 함께 `"이미 온몸이 뽀송뽀송 윤기나요 몽! 🫧"`, 행복도 100% 시 뜀박질과 함께 `"지금 기분이 최고조라 너무 행복해요! 🐾"`, 에너지 방전 시 `"너무 지쳐서 뛸 힘이 없어요 💤"` 리액션 제공.
    - **어뷰징 방지**: 100% 상태에서의 연타 시 경험치(+EXP) 미지급 및 Supabase `petmong_activities` 중복 활동 로그 기록 차단.
  - **[🎮 반려몽 놀이터] 전용 미니게임 허브**: 거추장스러운 개별 서랍장을 제거하고, 케어 허브 내 `[🎮 놀이터]` 전용 버튼을 통해 4대 체류형 미니게임(간식 캐치, 핑퐁 랠리, 버블 팝, 별자리 잇기)을 언제든 자유롭게 탐색하고 도전할 수 있는 카드형 오락실 모달 제공.
  - **다마고치 시간 경과 자연 소모 (Time-based Vital Decay)**: 마지막 케어 시점으로부터 경과된 시간에 비례하여 포만감, 행복도, 청결도, 에너지가 현실감 있게 자연 감소(최저 15% 안전선 보장)하며, 컨디션에 따라 배고픔(`꼬르륵...`), 목욕(`꼬질꼬질...`), 수면(`하아암...`) 필요 상태를 스스로 말풍선으로 표현.
  - **온 가족 실시간 케어 로그 (`petmong_activities`)**: 가족 구성원이 밥주기, 놀기, 목욕, 재우기를 실행할 때마다 `"${name}님이 몽이에게 맛있는 사료를 챙겨주었습니다 🥫"` 활동 내역이 기록되어 온 가족 화면에 실시간 동기화.
  - **가족 거실 룸 & 미니멀 2대 액션 헤더**: 상단 우측 버튼을 **[귓속말 💌]**, **[거실 테마 🎨]** 2가지 핵심 액션으로 극대화 정돈하고, 성장 도감은 좌측의 직관적인 반려몽 레벨 칩(`🐾 몽이 [Lv.N] 📖`) 및 반려몽 탭 컨디션 팝업을 통해 자연스럽게 원터치 진입 지원.
- **우리 가족 반려친구 4단계 성장 앨범 (`PetmongGrowthBookModal.js`)**:
  - **사용자 맞춤 이름 기반 성장 단계**: 사용자가 지어준 이름을 전면 활용하여 **1단계(아기 {name}, Lv.1~4) ➔ 2단계(개구쟁이 {name}, Lv.5~9) ➔ 3단계(든든한 짝꿍 {name}, Lv.10~19) ➔ 4단계(평생 식구 {name}, Lv.20+)**로 자연스럽게 깊어지는 가족 동반자 성장 체계 확립
  - **다채로운 앨범 진입점**: 상단 좌측 반려친구 프로필 칩(`🐾 {name} [Lv.N] 📖`), 캐릭터 머리 위 단계 배지, 컨디션 팝업 내 바로가기 지원
  - **단일 뷰 성장 타임라인**: 탭 분산 없이 창을 열면 곧바로 4단계의 과거 달성 모습, 현재 단계, 미래 성장 모습을 자유롭게 탭하여 인터랙티브 탐색
  - **직전 단계 기반 이미지 체이닝 (Sequential Chaining)**: 1단계 모습을 토대로 2단계가 생성되고, 2단계 모습을 이어받아 3단계, 4단계로 점진적 성장·진화하는 AI Image-to-Image 멀티모달 파이프라인
  - **단계별 비주얼 프리뷰 & 오라 연출**: 단계별 스케일(0.88x~1.35x), 단계 고유의 천상 오라(소프트 핑크 링, 싱그러운 새싹 오라, 코스믹 별빛 스카프, 수호신 황금 천사 날개 & 왕관) 및 이모지 성장 트리 시뮬레이션
  - **실제 온 가족 육성 가이드**: 밥주기 & 간식 캐치(대량 EXP), 놀아주기 & 쓰다듬기(친밀도), 데일리 스몰톡 & 집안일 연동 등 실질적인 인게임 육성 팁 제공
  - **귀여운 동물상 뱃지**: 내부 AI 비전 분석을 통해 감지된 가족 동물상(강아지상, 고양이상, 곰상 등)을 콤팩트한 뱃지로 표시
- **풀스크린 감성 거실 테마 & 반려친구 외형 센터 (Room Theme & Styling Hub)**:
  - **가구 배치 배제 & 완성형 감성 룸 테마 전환**: 복잡하고 시점이 어색한 개별 가구 배치 방식 대신, 감성 높은 완성형 룸 일러스트 배경 스킨 5종(코티지 원목, 파스텔 핑크, 미드나잇 다락방, 낮 햇살, 달빛 밤)을 원터치로 전환하여 가족 전 기기에 실시간 동기화
  - **2단 세그먼트 모달**: 상단 `[거실 테마 🎨]` 터치 시 열리는 모달 내에서 `[🎨 거실 테마 (5종)]`과 `[🪄 반려친구 외형 변경]`을 한곳에서 간결하게 관리
- **반려친구 비밀 귓속말 & 감성 편지 배달부 (Secret Whisper Courier)**:
  - **가족 지정 비밀 쪽지 보관**: 가족 구성원 중 한 명을 콕 집어 전하고 싶은 다정한 응원이나 쑥스러운 비밀 메시지를 반려친구에게 맡겨두는 감성 비동기 소통 시스템
  - **수신자 입장 시 실시간 알림**: 수신 가족이 거실에 입장하면 반려친구 머리 위에 통통 튀는 엽서 배지(`💌 비밀 귓속말 (N)`)가 떠오르며 `"쉿! 저한테 몰래 맡겨진 비밀 귓속말이 있어요! 💌"` 전용 말풍선 연출
  - **빈티지 감성 엽서 모달 & 읽음 보상**: 편지 개봉 시 아날로그 감성 엽서 UI로 메시지를 읽을 수 있으며, `[고마워 하트 보내기 💖]` 터치 시 즉시 읽음 처리 및 경험치(+10 EXP)와 활동 로그 기록
  - **원터치 답장 & 보관함 연동**: `[나도 답장 귓속말 남기기 💌]`로 발신자에게 즉시 답장을 보낼 수 있으며, 상단 헤더 `[귓속말 💌]` 버튼을 통해 새 편지 쓰기 및 미확인 편지 목록 열람 가능
- **온 가족 맞춤 AI 성장 엔진**:
  - **4단계 맞춤 성장 시스템**: 일률적 템플릿 탈피, 각 동물상의 특징을 바탕으로 아기 시절 ➔ 개구쟁이 단짝 ➔ 든든한 짝꿍 ➔ 평생 식구로 단계적 성장
  - **실제 사진 기반 멀티모달 Image-to-Image AI 생성**: 단순 텍스트 프롬프트 추론에서 벗어나, 업로드한 가족 사진 원본을 Gemini 2.5 Flash 비전 분석 및 Gemini Flash Image 모델(`gemini-2.5-flash-image`, `gemini-3.1-flash-image`)에 직접 멀티모달 입력하여 표정, 눈매, 고유 색상 팔레트를 온전히 반영하는 2D 귀여운 'Sumone' 감성 마스코트 캐릭터 실시간 생성
  - **500P 반려친구 외형 변경 & 환생 시스템 (`InteriorScreen.js`)**: 최초 1회 입주는 무료(0P)이며, 이후 가족 구성원 누구나 `[거실 테마 🎨]` 모달의 `[반려친구 외형 변경]` 탭을 통해 500 가족 포인트(P)를 사용하여 기존 누적 레벨(Lv) 및 경험치(EXP)를 영구 보존하면서 새로운 사진으로 외형을 리디자인/환생 가능. 변경 즉시 가족 활동 내역(`petmong_activities`)에 실시간 동기화
  - **다마고치 4대 생체 게이지 서버 중앙 동기화**: 배고픔(`🍗`), 행복도(`💖`), 청결도(`🧼`), 에너지(`⚡`)가 Supabase `petmong_activities`의 `VITALS_UPDATE` 활동 로그 및 가족 전 기기 Realtime 채널을 통해 중앙 동기화되어 온 가족이 동일한 반려친구 컨디션을 실시간 공유
  - **가족 터치 교감 및 실시간 반응**: 일일 10회 터치 교감 및 경험치(+30 EXP) 획득, "OO님이 쓰다듬어 주셔서 기분이 너무 좋아요!" 실시간 말풍선 반응 제공

  - 질문별 가족 구성원 아바타, 이름/역할 뱃지, 등록 일자, 대화 말풍선 배치
  - `[포토북에 담기 📖]` 원터치 토글 버튼을 지원하여 원하는 가족 문답만 쏙 골라 포토북 인터뷰 챕터로 수록
- **가족 그룹 생성일(`family_created_at`) 기준 동적 월별 필터링 & 연·월 모달 피커**:
  - 가족 그룹이 생성된 월부터 현재까지의 기간만 동적으로 계산하여, 생성일 이전의 무의미한 질문 노출 원천 차단

  - **`[🗓️ 연·월 선택]` 모달 피커 (`MonthPickerModal`)**: 수년 치 가족 문답이 누적되더라도 연도별 아코디언 및 월별 그리드를 통해 원하는 과거 시점으로 1초 만에 점프 탐색 가능

  - `FamilyStorybookModal.js`와 원터치 연동되어 완성된 책을 실제 책장 넘기듯 양면 펼침면(Spread)으로 미리보기
  - 가족들이 함께 모은 포인트(P)를 차감하여 A5 규격 300DPI 고급 하드커버 양장본 실물 인쇄 및 배송 신청 연동

- **POD Architecture**: 실물 양장 하드커버/소프트커버 규격 도서 발주 인터페이스

### Backend & Infrastructure
- **Database & Auth**: Supabase (PostgreSQL, Supabase Auth, Row Level Security)
- **Real-time Sync**: Supabase Realtime Channels (PostgreSQL Websocket)
- **Storage**: Supabase Storage (`family-photos` bucket) & Base64 Data URL Fallback
- **Push Service**: Expo Push Notification Service

## 🚀 시작하기 (Getting Started)

### 1. 프로젝트 클론 및 패키지 설치
```bash
git clone https://github.com/LYHTemptation/FamLink.git
cd FamLink
npm install
```

### 2. 환경 변수 (`.env`) 설정
프로젝트 루트 디렉토리에 `.env` 파일을 생성하고 Supabase 및 Gemini 접속 정보를 작성합니다:
```env
EXPO_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
EXPO_PUBLIC_GEMINI_API_KEY=your-gemini-api-key
```

### 3. Supabase 데이터베이스 구축
Supabase 대시보드의 **SQL Editor**에서 프로젝트 내 [`supabase_schema.sql`](./supabase_schema.sql) 파일의 전체 SQL 스크립트를 붙여넣고 실행합니다.

### 4. 앱 실행
```bash
# Expo 개발 서버 시작 (웹/모바일)
npm start

# 웹 브라우저에서 바로 열기
npm run web
```
- **Android**: 스마트폰의 `Expo Go` 앱으로 터미널의 QR 코드를 스캔
- **iOS**: 스마트폰 카메라 앱으로 QR 코드를 스캔하여 `Expo Go`로 열기

### 5. 앱 빌드 및 추출 (EAS Build)
```bash
# 안드로이드 프리뷰 빌드 실행 (APK 추출)
eas build -p android --profile preview
```

## 🛡️ 무결성 검증 및 README 최신화 가이드 (Verification & Docs Sync)

FamLink는 코드 품질 무결성과 최신 문서 동기화를 위해 자동화 스크립트 및 에이전트 강제 규칙이 설정되어 있습니다:

```bash
# 1. 문법 오류(SyntaxError) 및 미선언 식별자(ReferenceError) 전수 정적 분석
npm run check:syntax

# 2. 컴포넌트-문서 동기화 상태 점검
npm run docs:sync

# 3. 올인원 사전 검증 (Syntax Check + Docs Sync)
npm run verify
```
- **사전 무결성 검증 ([scripts/check-syntax.js](./scripts/check-syntax.js))**: Babel AST Parser & Traversal을 통해 프로젝트 소스 코드(28개+) 전체를 스캔하여 런타임 `ReferenceError`(import 누락, 미정의 훅/함수 호출 등)를 사전에 100% 탐지·차단합니다.
- **AI Agent 개발자 규칙 ([AGENTS.md](./AGENTS.md))**: 기능 추가 및 리팩토링 후 반드시 `npm run verify`를 실행하여 정적 무결성을 통과한 뒤에만 완료하도록 시스템 레벨에서 강제되어 있습니다.
