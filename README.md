# 🏡 FamLink (팜링크) - 가족 전용 소통 & 게이미피케이션 플랫폼

> **"대화가 줄어든 가족에게 따뜻한 소통의 핑계를 선물합니다."**  
> **FamLink**는 가족 전용 단톡방/1:1 메신저, 데일리 소통 미션(스몰톡), 공유 캘린더, 장보기 체크리스트, 가족 포인트 통장 & 입출금 내역장, 그리고 **온 가족이 함께 모은 포인트로 실물 책을 제작·인쇄하는 AI 가족 이야기책 출판 스튜디오**가 결합된 **가족 전용 올인원 게이미피케이션 라이프스타일 플랫폼**입니다.

---

## 🌟 주요 기능 (Key Features)

### 0. 🏠 FamLink 통합 홈 대시보드 (Figma Design Home Dashboard)
- **Figma 디자인 기반 올인원 대시보드 (`HomeScreen.js`)**:
  - **패밀리 헤더 & 날짜/인사말**: 오늘의 날짜, 맞춤 가족 인사말(`Good morning, 우리 가족 👋`) 및 포인트 뱃지(`⭐ 1240 pts`) 상시 표시
  - **가족 구성원 퀵 레일**: 역할/프로필별 고유 컬러 링 아바타 및 `+` 멤버 초대 버튼
  - **오늘 함께 진행도 (`Today's Together Activities`)**: 코랄-오렌지 그라디언트 캡슐 게이지 및 완료 잔여량 실시간 트래킹
  - **우리 가족 반려몽 전용 위젯 (썸원식 가족 온기 브리핑)**: 페리윙클 카드에 현재 반려몽 성장 단계(`Lv.N {stage}`), 오늘 가족 대화 온기(`🔥 N%`), 다음 진화 경험치(`🌱 N%`), 자율 루틴 말풍선 프리뷰(`💬`) 및 온기 열매 결실(`🍇`) 뱃지 실시간 표시, 1-tap 거실 진입
  - **Family Chat 프리뷰 카드**: 가족 단톡방의 최신 4개 대화 스니펫 및 `Open chat →` 다이렉트 이동
  - **Your Family Book 출판 티저**: 이번 달 수집된 추억 통계 및 글래스모피즘 `Preview book →` 바로보기 연동

### 1. 💬 가족 실시간 메신저 (Advanced Chat System)
- **1:1 격리 대화방 & 단체 수다방**: 독립된 1:1 대화방(대칭 룸 ID)과 전체 가족 수다방 완벽 분리
- **카카오톡 스타일 읽음 카운터 (`1`, `2`)**: 상대방이 메시지를 읽는 즉시 실시간으로 숫자가 차감되는 투명한 읽음 확인
- **0ms 초고속 낙관적 UI (Optimistic UI)**: 메시지 전송 버튼을 누르는 즉시 화면에 반응하고 백그라운드에서 동기화
- **클라이언트 고화질 이미지 95% 압축 (`compressImageForChat`)**: 4K 스마트폰 사진을 80KB 수준으로 고속 압축 전송
- **PC 웹 & 모바일 UX 최적화**: 
  - PC 환경에서 `Enter` 즉시 전송 & `Shift + Enter` 줄바꿈 지원
  - 모바일 가상 키보드 가림 완벽 방지 (`KeyboardAvoidingView` + 홈 바 세이프 패딩)
- **스마트 상단 하이라이트 배너**: 오늘의 스몰톡 미션 상태 및 최근 답변 실시간 프리뷰
- **시스템 스페셜 알림 카드**: 실물 책 발주 시 골드/코랄 축하 카드로 단톡방 자동 공지

### 2. 🤝 오늘 함께 허브 (Together Hub - SmallTalk, Chores & Games)
*가족의 하루 소통(스몰톡), 생활 루틴(집안일), 온가족 미니게임을 편안하게 함께 즐기며 가족 포인트(P)를 모으는 패밀리 라이프스타일 허브입니다.*

#### 💬 [상단 고정] 데일리 스몰톡 (소통 미션)
- **일일 질문 자동 순환**: 매일 새로운 대화 주제를 던져주어 가족 간 자연스러운 대화 유도
- **고유 프로필 기반 답변 격리**: 동일한 역할(예: 아들 2명) 사용자 간에도 답변이 섞이지 않는 1:1 고유 UUID 매핑
- **개인 기여 + 가족 전원 보너스 이원화 보상**: 답변 작성 시 1인당 **+5P** 즉시 적립 + 가족 전원 답변 완료 시 **+30P** 올클리어 보너스 지급 (대규모 가족도 소외 없이 안정적 적립)
- **10인 가족 전용 UI/UX 최적화**: 10인 대가족 환경에서도 스크롤 없이 바로 쓸 수 있는 **답변창 상단 우선 배치** 및 **가족 참여 현황 퀵 레일(가로 아바타 칩)** 제공
- **순수 대화 집중 레이아웃**: 가족들의 따뜻한 답변과 말풍선에 온전히 몰입

#### ① ✅ 서브 탭 1: 가족 장보기 & 집안일 (생활 미션)
- **담당자 지정 체크리스트**: 필요한 장보기 물품 및 집안일 등록 및 담당 가족 지정 (최대 10인 가족 아바타+이름 동시 지원)
- **매일/정기 반복 할 일 설정 & 자정 자동 갱신**: 분리수거, 화분 물주기, 반려견 산책 등 매일 반복되는 집안일을 위한 반복 설정(`반복 없음` / `매일 반복` / `매주 반복`) 지원, 자정 이후 새로운 오늘 할 일로 자동 리셋 및 완료 비우기 시 루틴 데이터 영구 보존
- **순수 SVG 반복 아이콘(`IconRepeat`) 연동**: 이모티콘 없이 직관적인 SVG 벡터 뱃지 탑재 및 원터치 반복 전환 토글 지원
- **어뷰징 방지 보상 시스템**: 최초 1회 체크 시 1건당 **+10P ~ +20P** 지급, 하루 최대 30P(3건)로 일일 캡 제한
- **임베디드 컴팩트 뷰**: 별도 화면 이동 없이 한곳에서 원스톱으로 체크 및 추가 가능

#### ② 🎮 서브 탭 2: 패밀리 게임 & 반려몽 액션 놀이터 (협동 미션)
- **온 가족 체류형 인터랙티브 4대 미니게임 (가족 포인트 전용 획득)**:
  - **제1탄 [와구와구 간식 캐치] (`SnackCatchGame.js`)**: 하늘에서 떨어지는 사과, 고기, 케이크, 별사탕을 반려몽을 직접 좌우로 스와이프 조작하여 받아먹는 아케이드 캐치 게임. 폭탄과 매운 고추 회피, 8콤보 피버 타임(2배 점수), 등급별 최대 **+100 P** 적립.
  - **제2탄 [핑퐁 리프팅 랠리] (`KeepyUppyGame.js`)**: 공이 바닥에 떨어지지 않도록 유저가 손가락 패들로 튕겨 올려 반려몽과 탁구/배구 랠리를 이어가는 인터랙티브 핑퐁 게임. 랠리 횟수 콤보, 점진적 속도 증가 긴장감, 최고 랠리 기록 갱신 및 최대 **+120 P** 적립.
  - **제3탄 [뽀득뽀득 버블 팝] (`BubblePopGame.js`)**: 반려몽 몸 주변에 피어오르는 무수한 비누방울을 손가락으로 연속 탭/스와이프하여 팡팡 터트리는 쾌감 액션. 황금 거품/시간 연장 거품 기믹 및 최대 **+100 P** 적립.
  - **제4탄 [꿈나라 별자리 잇기] (`DreamConstellationGame.js`)**: 밤하늘 천장의 빛나는 별들을 순서대로 선으로 이어 별자리를 완성하는 힐링 감성 퍼즐. 완성도에 따라 최대 **+150 P** 적립.

### 4. 🐾 가족 대화 흡수 자율 성장 반려몽 & 감성 룸 (Family Warmth & Routine Engine)
- **가족 대화 흡수 자율 성장 시스템 (썸원 방식, `PetmongGameEngine.js`)**:
  - **노동성 다마고치 케어 탈피**: 90년대식 단순 노동성 버튼(밥/목욕/놀이/잠)을 제거하고, 가족들의 실제 대화와 상호작용을 양분 삼아 자율적으로 성장하는 모던 방치형 힐링 엔진 도입.
  - **가족 대화 온기 게이지 (0~100%)**: 오늘 가족 단톡방에서 나눈 메시지 수와 데일리 스몰톡 답변 참여율을 실시간 분석하여 온기 지수를 산출.
  - **펄스 온기 열매 수확 시스템**: 가족 대화가 누적되어 온기가 차오르면 캐릭터 머리 위에 반짝이는 '온기 열매'가 결실을 맺으며, 터치 수확 시 경험치(+25 EXP)와 가족 포인트(+30P) 지급.
  - **5대 자율 일상 루틴 (Autonomous Living Routines)**:
    - 반려몽이 거실 안에서 스스로 독서하기(`reading`), 가족 앨범 감상(`photo`), 창밖 풍경 구경(`window`), 깜빡 낮잠(`napping`), 방긋 미소(`happy`)를 20초마다 자연스럽게 순환 전환.
    - 각 루틴에 맞춘 따뜻한 가족 사랑 말풍선 대사 출력.
  - **애니메이션 스쿼시 & 터치 교감 (Squish & Bounce)**:
    - 반려몽을 탭하면 탄성 있는 젤리 스쿼시 모션과 함께 하트가 퐁퐁 솟아오르며, 오늘의 가족 온기 상태와 소통 현황을 한눈에 보여주는 감성 '가족 온기 카드' 모달 오픈.
  - **미니멀 플로팅 하단 바**:
    - `[온기 열매 수확]` & `[조명 끄기/켜기]` 2가지 필수 액션으로 하단을 깔끔하게 정돈하여 거실 테마와 반려몽의 귀여운 일상을 시각적으로 온전히 감상 가능.
- **우리 가족 반려친구 4단계 성장 앨범 (`PetmongGrowthBookModal.js`)**:
  - **사용자 맞춤 이름 기반 성장 단계**: 사용자가 지어준 이름을 전면 활용하여 **1단계(아기 {name}, Lv.1~4) ➔ 2단계(개구쟁이 {name}, Lv.5~9) ➔ 3단계(든든한 짝꿍 {name}, Lv.10~19) ➔ 4단계(평생 식구 {name}, Lv.20+)**로 자연스럽게 깊어지는 가족 동반자 성장 체계 확립
  - **다채로운 앨범 진입점**: 상단 좌측 반려친구 프로필 칩(`🐾 {name} [Lv.N] 📖`), 캐릭터 머리 위 단계 배지, 온기 모달 내 바로가기 지원
  - **직전 단계 기반 이미지 체이닝 (Sequential Chaining)**: 1단계 모습을 토대로 2단계가 생성되고, 2단계 모습을 이어받아 3단계, 4단계로 점진적 성장·진화하는 AI Image-to-Image 멀티모달 파이프라인
  - **단계별 비주얼 프리뷰 & 오라 연출**: 단계별 스케일(0.88x~1.35x), 단계 고유의 천상 오라(소프트 핑크 링, 싱그러운 새싹 오라, 코스믹 별빛 스카프, 수호신 황금 천사 날개 & 왕관) 및 이모지 성장 트리 시뮬레이션
  - **실제 온 가족 육성 가이드**: 가족 대화 나누기, 스몰톡 답변, 온기 열매 수확, 패밀리 미니게임 연동 등 실질적인 인게임 육성 팁 제공
- **풀스크린 감성 거실 테마 & 반려친구 외형 센터 (Room Theme & Styling Hub)**:
  - **가구 배치 배제 & 완성형 감성 룸 테마 전환**: 복잡하고 시점이 어색한 개별 가구 배치 방식 대신, 감성 높은 완성형 룸 일러스트 배경 스킨 5종(코티지 원목, 파스텔 핑크, 미드나잇 다락방, 낮 햇살, 달빛 밤)을 원터치로 전환하여 가족 전 기기에 실시간 동기화
  - **2단 세그먼트 모달**: 상단 `[거실 테마 🎨]` 터치 시 열리는 모달 내에서 `[🎨 거실 테마 (5종)]`과 `[🪄 반려친구 외형 변경]`을 한곳에서 간결하게 관리
- **반려친구 비밀 귓속말 & 감성 편지 배달부 (Secret Whisper Courier)**:
  - **가족 지정 비밀 쪽지 보관**: 가족 구성원 중 한 명을 콕 집어 전하고 싶은 다정한 응원이나 쑥스러운 비밀 메시지를 반려친구에게 맡겨두는 감성 비동기 소통 시스템
  - **수신자 입장 시 실시간 알림**: 수신 가족이 거실에 입장하면 반려친구 머리 위에 통통 튀는 엽서 배지(`💌 비밀 귓속말 (N)`)가 떠오르며 `"쉿! 저한테 몰래 맡겨진 비밀 귓속말이 있어요! 💌"` 전용 말풍선 연출
  - **빈티지 감성 엽서 모달 & 읽음 보상**: 편지 개봉 시 아날로그 감성 엽서 UI로 메시지를 읽을 수 있으며, `[고마워 하트 보내기 💖]` 터치 시 즉시 읽음 처리 및 경험치(+10 EXP)와 활동 로그 기록
  - **원터치 답장 & 보관함 연동**: `[나도 답장 귓속말 남기기 💌]`로 발신자에게 즉시 답장을 보낼 수 있으며, 상단 헤더 `[귓속말 💌]` 버튼을 통해 새 편지 쓰기 및 미확인 편지 목록 열람 가능
- **온 가족 맞춤 AI 성장 엔진**:
  - **4단계 맞춤 성장 시스템**: 일률적 템플릿 탈피, 각 동물상의 특징을 바탕으로 아기 시절 ➔ 개구쟁이 단짝 ➔ 든든한 짝꿍 ➔ 평생 식구로 단계적 성장
  - **실제 사진 기반 멀티모달 Image-to-Image AI 생성**: Gemini 2.5 Flash 비전 분석 및 Flash Image 모델을 통해 가족 사진의 개성을 온전히 반영하는 귀여운 'Sumone' 감성 마스코트 캐릭터 실시간 생성
  - **500P 반려친구 외형 변경 & 환생 시스템 (`InteriorScreen.js`)**: 가족 누구나 500P로 누적 레벨과 경험치를 보존하며 새 사진으로 외형을 리디자인/환생 가능

- **헤더 프로필 터치 이동 & 안전한 로그아웃**: 상단 헤더 내 프로필 칩 클릭으로 가족 관리 화면으로 이동, 가족 화면 내 전용 로그아웃 버튼 배치

### 6. 📸 가족 추억 앨범 & 6개월 포토북 스튜디오 (Photo Album & 6-Month Photobook Studio)
- **차세대 6개월 반기 포토북 스튜디오 (`PhotobookStudioScreen.js`)**:
  - **150×150mm 코지 스퀘어 (15×15cm) 32P 하드커버 양장본 특화**: 스마트폰 한 화면에 가장 큼직하고 안정적으로 들어오는 1:1 완벽 정방형 캔버스 기반 조판 스튜디오
  - **캔버스 직상단 스마트 HUD 툴바 & 반응형 팝오버**: `[ 🎨 테마 (2×2 반응형 그리드) ]` + `[ 🔤 폰트 & 크기 ]` + `[ 📐 레이아웃 (포맷 1·2·3 및 분할) ]` + `[ 📖 페이지 선택 (4×4 콤팩트 그리드 즉시 점프 팝오버) ]`
  - **모바일 화면 최적화 반응형 다이얼로그**: 스마트폰 화면을 뒤덮던 긴 세로 리스트를 탈피하고, 화면의 35~40%만 차지하는 정중앙 콤팩트 카드와 배경 탭 닫기를 적용하여 조판 캔버스 시야 유지 및 모든 아이폰 해상도에 완벽 대응
  - **좌우 스와이프 페이징 (Swipeable Spreads Scroll)**: 페이지 편집 모드에서도 실제 책장을 넘기듯 손가락 좌우 스와이프로 16개 스프레드를 자연스럽게 페이징 탐색
  - **3대 코어 출판 포맷 체계**:
    - **포맷 1 [ 🖼️ 사진 전용 ]**: 15×15 1:1 전면 사진(터치 시 즉시 사진 교체, 1장/2장 분할 지원) + AI 감성 글귀 리본
    - **포맷 2 [ 💬 스몰톡 전용 ]**: 선택된 서체·크기에 맞춰 정갈하게 조판된 가족 180문답 인터뷰 에세이 페이지
    - **포맷 3 [ 📑 사진 + 스몰톡 (FamLink 시그니처) ]**: 상단 52% 현장 사진 1장 + 하단 44% 질문 1개와 가족 답변이 결합된 하이브리드 페이지
  - **듀얼 뷰포트 [페이지, 스크롤]**: 상단 우측 원터치 스위처로 1:1 완벽 단면/양면 페이지 편집 모드와 겉표지~P.32 전체 연속 피드 스크롤 감상 모드를 인플레이스 전환
  - **비즈니스 POD 커머스 & 반기 정기 구독 연동**: 150×150mm 코지 스퀘어 고급 양장 하드커버(랑데뷰 160g) 1권 24,000원(포인트 최대 12,000P 할인 지원), 조부모님 선물용 추가 1권(+14,000원) 특가 및 가족 단톡방 주문 알림 연동
- **직관적인 2단 서브탭 구조 (`[📖 포토북 스튜디오]` / `[💬 스몰톡 아카이브]`)**:

- **Supabase DB 기반 스몰톡 질문 관리 (`small_talk_topics`) & 이모티콘 전면 배제**:
  - 질문 리스트를 코드 하드코딩에서 Supabase DB 테이블(`small_talk_topics`) 기반으로 마이그레이션하여 패밀리별 질문 관리 및 실시간 동기화 지원
  - 질문 생성 및 렌더링 시 이모티콘(이모지)을 전면 제거하여 정갈하고 가독성 높은 한국어 문장 큐레이션 제공

  - `[포토북에 담기 📖]` 원터치 토글 버튼을 지원하여 원하는 가족 문답만 쏙 골라 포토북 인터뷰 챕터로 수록

## 🛠 기술 스택 (Tech Stack)

### Frontend
- **Framework**: React Native (Expo SDK 54), React 19, React Native Web
- **Icons & UI**: `lucide-react-native`, React Native StyleSheet (반응형 모바일 & 웹 레이아웃)
- **Media & Hardware**: `expo-image-picker`, `expo-notifications`, `expo-device`
- **Storage**: `@react-native-async-storage/async-storage`

### AI & 출판 엔진
- **AI Models**: Google Gemini (`gemini-2.5-flash`), Imagen (`imagen-4.0-generate-001`)
- **Print Engine**: CSS3 `@media print`, 150×150mm 코지 스퀘어 표준 판형 300 DPI 벡터/타이포그래피 출판 레이아웃
- **POD Architecture**: 실물 양장 하드커버/소프트커버 규격 도서 발주 인터페이스

### Backend & Infrastructure
- **Database & Auth**: Supabase (PostgreSQL, Supabase Auth, Row Level Security)
- **Real-time Sync**: Supabase Realtime Channels (PostgreSQL Websocket)
- **Storage**: Supabase Storage (`family-photos` bucket) & Base64 Data URL Fallback
- **Push Service**: Expo Push Notification Service

## 🚀 시작하기 (Getting Started)

### 1. 프로젝트 클론 및 패키지 설치
```bash
git clone https://github.com/LYHTemptation/FamLink.git
cd FamLink
npm install
```

### 2. 환경 변수 (`.env`) 설정
프로젝트 루트 디렉토리에 `.env` 파일을 생성하고 Supabase 및 Gemini 접속 정보를 작성합니다:
```env
EXPO_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
EXPO_PUBLIC_GEMINI_API_KEY=your-gemini-api-key
```

### 3. Supabase 데이터베이스 구축
Supabase 대시보드의 **SQL Editor**에서 프로젝트 내 [`supabase_schema.sql`](./supabase_schema.sql) 파일의 전체 SQL 스크립트를 붙여넣고 실행합니다.

### 4. 앱 실행
```bash
# Expo 개발 서버 시작 (웹/모바일)
npm start

# 웹 브라우저에서 바로 열기
npm run web
```
- **Android**: 스마트폰의 `Expo Go` 앱으로 터미널의 QR 코드를 스캔
- **iOS**: 스마트폰 카메라 앱으로 QR 코드를 스캔하여 `Expo Go`로 열기

### 5. 앱 빌드 및 추출 (EAS Build)
```bash
# 안드로이드 프리뷰 빌드 실행 (APK 추출)
eas build -p android --profile preview
```

## 🛡️ 무결성 검증 및 README 최신화 가이드 (Verification & Docs Sync)

FamLink는 코드 품질 무결성과 최신 문서 동기화를 위해 자동화 스크립트 및 에이전트 강제 규칙이 설정되어 있습니다:

```bash
# 1. 문법 오류(SyntaxError) 및 미선언 식별자(ReferenceError) 전수 정적 분석
npm run check:syntax

# 2. 컴포넌트-문서 동기화 상태 점검
npm run docs:sync

# 3. 올인원 사전 검증 (Syntax Check + Docs Sync)
npm run verify
```
- **사전 무결성 검증 ([scripts/check-syntax.js](./scripts/check-syntax.js))**: Babel AST Parser & Traversal을 통해 프로젝트 소스 코드(28개+) 전체를 스캔하여 런타임 `ReferenceError`(import 누락, 미정의 훅/함수 호출 등)를 사전에 100% 탐지·차단합니다.
- **AI Agent 개발자 규칙 ([AGENTS.md](./AGENTS.md))**: 기능 추가 및 리팩토링 후 반드시 `npm run verify`를 실행하여 정적 무결성을 통과한 뒤에만 완료하도록 시스템 레벨에서 강제되어 있습니다.
