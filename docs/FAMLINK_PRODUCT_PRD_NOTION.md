# 📖 FamLink (팸링크) 서비스 기획 명세서 & PRD (Notion Import Ready)

> **"가족의 사소한 오늘이 모여 평생의 온기가 되는 곳"**  
> FamLink는 **매일의 실시간 가족 소통(채팅·캘린더·장보기)**, **체류형 인터랙티브 육성(반려몽·4대 미니게임)**, 그리고 **6개월간의 소중한 기록을 영구 소장 도서로 출판하는 실물 커머스(32P 양장본 스토리북)**가 하나로 결합된 올인원 패밀리 라이프스타일 플랫폼입니다.

## 2. 타깃 고객 및 사용자 페르소나

### 🎯 Primary Target: 3040 부모 & 1020 자녀 (초·중·고·대학생)
- **부모 페르소나 (40대 후반 엄마/아빠)**:
  - "아이들이 크면서 대화가 줄어들어 아쉬워요. 단톡방엔 잔소리밖에 안 남아요."
  - 가족의 따뜻한 추억을 책이나 실물 앨범으로 영구 소장하고 싶어 함.
- **자녀 페르소나 (10대 중후반~20대 초반 자녀)**:
  - "부모님과 대화하는 게 가끔 어색해요. 귀여운 캐릭터나 가벼운 미니게임이 있으면 참여하기 편해요."
  - 짧은 한 줄 문답(스몰톡)과 귀여운 반려몽 육성 요소에 흥미를 느낌.

### 🎯 Secondary Target: 조부모 및 독립 가구 1인 자녀
- 조부모님께 손자·손녀의 성장 사진과 가족들의 안부를 선물용 도서로 실물 배송(+1권 추가 제작).

## 3. 핵심 기능 상세 명세

### 3.1 홈 대시보드 & 스마트 캘린더
- **오늘의 가족 상태 위젯**: 가족 구성원별 기분, 외출/재택 상태, 당일 핵심 일정 실시간 요약.
- **한국 공휴일 2024~2030 자동 연동 (`utils/koreanHolidays.js`)**:
  - 신정, 설날/추석 연휴, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절 및 **대체공휴일** 자동 계산.
  - 달력 날짜 빨간색 표시 및 날짜 하단 공휴일 명칭 배지 제공.
  - 상단 "이달의 연휴 알림 카드" 및 홈 화면 오늘 일정 상단 자동 브리핑.
- **가족 D-Day 카운트다운**: 부모님 결혼기념일, 가족 생일, 수능/입학식 등 디데이 캐러셀 제공.

### 3.2 실시간 가족 채팅 & 장보기 메모
- **Supabase Realtime 채팅 (`ChatScreen.js`)**:
  - 가족 단체방 및 1:1 비밀 대화 지원, WebSocket 실시간 브로드캐스팅.
  - 사진 업로드 시 포토북 사진 보관함으로 자동 인덱싱.
- **체크리스트형 실시간 장보기 (`ShoppingListScreen.js`)**:
  - 장보기 품목 추가, 구매 완료 체크, 가족 간 실시간 동기화.

### 3.3 데일리 스몰톡 & 6개월 아카이브
- **데일리 스몰톡 (`SmallTalkScreen.js`, `services/smallTalkService.js`)**:
  - 매일 밤 10시 가족 질문 자동 도착 (Gemini 2.5 Flash & 180문답 정선 DB 연동).
  - 감정 이모티콘을 배제한 문학적·공감형 질문 큐레이션.
  - 온 가족 답변 완독 시 **가족 활동 포인트(P)** 보상 지급.
- **6개월 아카이브 (`PhotoAlbumScreen.js`)**:
  - 180일간의 모든 질문과 가족 답변을 월별(1월~6월) 패스트 점프로 즉시 검색.
  - `[포토북에 담기 🔖]` 원터치 토글 지원.

### 3.4 체류형 반려몽 육성 & 4대 인터랙티브 미니게임
- **반려몽 4대 케어 액션 연동 미니게임 (`PetmongGameEngine.js`, `components/minigames/*`)**:
  1. 밥주기 (`🍗`) → **[와구와구 간식 캐치] (Snack Rush)**: 30초 스와이프 캐치 아케이드 (폭탄 회피, 8콤보 피버).
  2. 놀아주기 (`⚽`) → **[핑퐁 리프팅 랠리] (Keepy-Uppy)**: 손가락 패들 반사신경 핑퐁 배구.
  3. 목욕하기 (`🧼`) → **[뽀득뽀득 버블 팝] (Bubble Pop Frenzy)**: 무수한 비누방울 연속 터치 액션.
  4. 재우기 (`🌙`) → **[꿈나라 별자리 잇기] (Dream Constellation)**: 밤하늘 별자리 연결 힐링 퍼즐.
- **4단계 AI 비전 맞춤 진화**: 디지몬/포켓몬 스타일 4단계 진화 및 3D 하우스 인테리어 가구 배치.

### 3.5 6개월 패밀리 스토리북 & 포토북 스튜디오 (`PhotobookStudioScreen.js`)
- **도서 사양**:
  - 판형: 150 × 150 mm (6×6 inch) 코지 스퀘어 고급 양장 하드커버
  - 본문: 총 **32페이지 (16 양면 스프레드)**, 최고급 랑데뷰 160g 무광 인쇄
- **1페이지 3문답 멀티 다이제스트 혁신 조판**:
  - 기존 1페이지 1문답 한계를 극복하고, **1페이지에 월간 3대 베스트 질문과 온 가족 답변(엄마/아빠/자녀)**을 콤팩트 카드형으로 다이제스트 조판.
  - 6개월 × 3개 = 총 **18개의 심층 인터뷰 챕터**와 해당 월의 사진 갤러리 2~4컷을 완벽 조화.
  - **[질문 교체]** 버튼으로 아카이브 내 원하는 질문으로 원터치 커스텀 교체 가능.
- **권말 180문답 전수 인덱스 부록 (P.29~30)**:
  - 6개월간 매일 나눈 180개의 모든 질문을 3단 초소형 타이니 인덱스로 빠짐없이 전수 수록하여 소장 가치 100% 확보.
- **3D 플립북 전체 넘겨보기 & 스마트 레이아웃 셔플 (전면/2분할/4분할)**.

## 4. 비즈니스 모델 & 하이브리드 토크노믹스

### 4.1 POD(Print-On-Demand) 실물 인쇄 커머스 가격 구조
- **정규 권당 소비자 정가**: `24,000원`
- **POD 제작 및 풀필먼트 원가**: 약 `10,000원 ~ 11,000원` (150×150mm 32P 양장 하드커버 기준)
- **가족 활동 포인트(P) 하이브리드 할인**:
  - 6개월간 가족이 스몰톡, 캘린더, 미니게임으로 적립한 포인트 사용 (1P = 1원).
  - **최대 할인 한도**: `12,000 P` 차감 가능.
  - **최저 실결제액**: `12,000원` (제작 원가를 안정적으로 상회하여 **절대 적자 없는 방어선 구축**).
- **선물용 추가 1권 주문 옵션**:
  - 조부모님/친척 선물용 동일 도서 추가 시: `+14,000원` (42% 특가 할인, 인쇄판형 공유로 순이익률 대폭 상승).

### 4.2 선순환 토크노믹스 플라이휠 (Flywheel)
```
[매일 스몰톡 & 미니게임 플레이] ──▶ [가족 포인트(P) 축적]
              ▲                               │
              │                               ▼
[다음 반기 포토북 제작 동기부여] ◀── [포토북 12,000원 할인 적용]
```

## 5. 시스템 아키텍처 & 기술 스택

- **프론트엔드 (Mobile & Web)**:
  - React Native (React 19), Expo SDK 54/57, React Native Web
  - Vector First UI (`lucide-react-native`, `react-native-svg`)
  - Figma Warm Cozy Living 디자인 시스템 토큰 (`#FF6B47`, `#FAF8F3`, `#FFF5F2`)
- **백엔드 & 데이터베이스**:
  - Supabase (PostgreSQL, Realtime WebSocket, Row Level Security)
  - Tables: `families`, `profiles`, `messages`, `small_talk_responses`, `small_talk_topics`, `petmong_characters`, `petmong_activities`, `calendar_schedules`
- **인공지능 (AI Engine)**:
  - Google Gemini 2.5 Flash: 스몰톡 질문 큐레이션, 에디토리얼 수필 집필, 사진 기반 AI 감성 글귀 자동 생성
  - Google Imagen 4.0: 반려몽 4단계 비전 진화 렌더링
